# MelaVerse Nepal — 3D Asset Licenses & Provenance

All 3D procedural meshes, geometries, shaders, color palettes, sound engines, and structures created for **MelaVerse Nepal** are original creations developed specifically for this project.

## Summary of Assets

1. **Avatar (Low-Poly Nepali Humanoid)**
   - **Creator**: MelaVerse Nepal Core Engine
   - **License**: Creative Commons Zero (CC0 1.0 Universal)
   - **Features**: Segmented procedural humanoid rig with Dhaka Topi, traditional Daura/Bhoto vest, Dashain Tika, and dynamic procedural kinematics (idle, walk, run, jump, namaste, nach, swinging).

2. **Linge Ping (Traditional Dashain Bamboo Swing)**
   - **Creator**: MelaVerse Nepal Core Engine
   - **License**: CC0 1.0 Universal
   - **Features**: 4-pole bamboo tetrahedral frame with apex rope lashings, suspended hemp cables, wooden swing seat, and dynamic pendulum harmonic oscillation physics.

3. **Langur Burja Game Booth**
   - **Creator**: MelaVerse Nepal Core Engine
   - **License**: CC0 1.0 Universal
   - **Features**: Traditional wooden gaming stall with green felt table, 6 traditional symbols (Jhanda, Burja, Ita, Paan, Hukum, Chidi), and dice cup.

4. **Tihar Rangoli & Diya Asset Pack**
   - **Creator**: MelaVerse Nepal Core Engine
   - **License**: CC0 1.0 Universal
   - **Features**: Concentric sacred lotus Rangoli floor mandala, 8 clay diya stations, low-poly flame meshes, and warm golden lighting.

5. **Modular Market Stall Kit (Bazaar Pavilion)**
   - **Creator**: MelaVerse Nepal Core Engine
   - **License**: CC0 1.0 Universal
   - **Features**: Reusable timber kiosk frames with customizable festive awnings (Chiya, Sel Roti, Changa kites, Dhaka textiles).

6. **Web Audio Sound Effects**
   - **Creator**: MelaVerse Nepal Procedural Sound Engine
   - **License**: MIT / CC0 (Synthesized in real-time via Web Audio API oscillators and gain envelopes — no third-party audio files required).
